# KEGG Enrichment Analysis of GCN2 in SMCs and Lung Tissue

R scripts for KEGG enrichment analysis of the following transcriptomic data:
Human pulmonary hypertension SMCs (GCN2 knockout).
Lung tissue and SMCs from wild-type and GCN2_SMC-/- mice (normal and MMC models).

## Requirement
 R >= 4.3.2 
Packages: `dplyr`, `ggplot2`

## Order of Execution
 GCN2_KEGG_analysis.R
